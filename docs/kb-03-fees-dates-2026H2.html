2. 折扣：有哪些，你能拿到哪些

折扣 幅度 你现在能拿到吗
IIC 早鸟报名价 $847 → $792（省 $55） ✅ 能，但只在 GIE 路线有用
IBABC 会员价（FOI 课程 $594 vs $694；CAIB 用书 $315 vs $415） 省 $100 ❌ 不能——仅限"受雇于会员经纪行"的人。找到工作后才能拿
ILScorp 团购价 未公开 ❌ 个人不适用
IIC 奖学金 / 助学金 视项目 ⚠️ 值得查一次：IIC Scholarships and bursaries
雇主报销 常见 100% ⚠️ 这是最大的一笔"折扣"。很多 BC 经纪行会报销新人的持牌费用（有的要求签服务期）。面试时一定要问
学院渠道（Camosun 等 IIBC 合作院校开设 IIBC 500V） 可能符合 BC 省学生资助 ⚠️ 若走 GIE 路线可查 IIC College Partners
IIC 可转售用书退回 退回用书，扣 $100 ✅ 考完后可回血一部分（仅 GIE 路线）

结论：以你当前"无雇主"的状态，能实际拿到的折扣只有 IIC 早鸟（且只在你选 GIE 时有意义）。 最有价值的省钱动作不是找折扣，而是：① 选 FOI（$360）② 一次考过（重考 $195 是最大的隐性成本）③ 面试时争取雇主报销。

3. 2026 下半年考期与考场

FOI（IBABC）—— 无固定考期，随时可约 ✅

监考方式 地点/时间 你能用吗
IBABC 温哥华办公室 每周二 13:00–15:30、每周三 09:00–11:30（PT）。迟到超 15 分钟不得入场，改期收 $75 ✅ 可用
IBABC 虚拟监考服务 线上，注册后收到预约日历链接 ✅ 推荐——最灵活
现职 nominee / 经纪行指定监考人 需企业邮箱（含姓名+公司名，不接受 Gmail / info@） ❌ 没工作用不了
认可学院 / 政府考试中心 仅限偏远地区 ❌ 不适用（你在 BC 大区）

流程：① 先选并支付监考 → ② 提前 3 个工作日在 Captus 考试注册系统 报名 → ③ 收到 candidate code → ④ 带 code + 英文政府证件应考 → ⑤ 交卷即出分。
