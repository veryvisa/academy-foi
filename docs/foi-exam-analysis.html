一、这份练习卷不覆盖汽车险，但考试考，而且是重点

题号顺序严格跟教材章节走，可以精确映射。映射完暴露一个缺口：

Chapter 12–14（汽车保险，共 83 页，占教材 21.8%）在这 90 题里一道都没有。

用户 2026-07-21 确认：汽车险考，而且是重点。 所以结论是—— 这份练习卷是部分卷，不是全卷；它的考点分布不能当作复习权重来用。

由此产生两条硬约束：

  1. 不要按下表的题数分配复习时间。 表里 Ch12–14 是 0 题，实际是重点。
  2. 汽车险三章缺练习题。 需要另找 BC 汽车险（ICBC Autoplan）的练习题源。 已有的 ~/Documents/ibabc-autoplan/autoplan_supplement.md（43 页 IBABC Autoplan 补编）正是这块内容，且第 42 页含一组 True/False 自测题—— 那是目前手上唯一的汽车险练习材料，学习阶段要重点用起来。

三、题型结构

约六成题目是「找例外」题——题干里带 except one / Select the Exception / which is incorrect / which is false。这类题的做法和正向题完全不同： 它要求你对四个说法逐条判真伪，只要有一条拿不准就没法排除。

含具体数字/金额/期限的计算或记忆题分布在： 第 14 题（生效时刻 12:01 am）、第 20 题（退保）、第 21 题（60 天 / 1 年时效）、 第 22 题（30 天）、第 31 题（成套物品）、第 33 题、第 39–40 题（特别限额）、 第 47 题（Coverage B 为 A 的 10%）、第 56 题（共保计算）、 第 86 题（怀孕 8 周）、第 89 题（Step-Licensing 三级）。

这些数字是最容易丢分也最容易补分的部分，建议单独做一张卡。

四、答案字母分布

C 和 D 合计 63.3%。这不构成猜题依据，但可以当作一个弱校验信号： 如果你做完一整套题发现自己选了一堆 A，值得回头复查。

五、贯穿全卷的主线（章节之间的连接点）

这几条线索横跨多章，是「串起来」的抓手：

  1. 保险合同的法律要件 → Ch2（要件、Consideration、行为能力） → Ch3（Insurance Act 何时生效、Statutory Conditions） → Ch5（Conditions vs Warranties 的违反后果） 同一个「合同」概念被切成三段讲，考试会跨段设题（第 6/14/28 题）。

  2. 赔偿原则 Indemnity → Ch5（Indemnity Agreement、ACV 定义） → Ch6（Homeowners 何时按重置成本、何时按 ACV） → Ch7（共保条款、复效条款） 核心问题始终是一个：赔多少。第 32/33/34/37/56 题是同一条线上的不同切面。

  3. 代位求偿 Subrogation → Ch5（第 16 题）→ Ch8/9/10（责任险的第三方追偿） 财产险和责任险在这里咬合。

  4. 经纪人的义务与责任 → Ch4（reasonable skill, care and diligence、E&O） → Ch3（fiduciary、保费信托）→ Ch15（执照、道德、吊销情形） 第 13/23/24/88/89/90 题是同一主题的首尾呼应。

  5. 除外与限额 → Ch5（一般除外）→ Ch6（特别限额、Basic vs Comprehensive） → Ch7（商业财产除外）。「什么不赔」比「什么赔」考得更多。
