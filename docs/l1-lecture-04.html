这一讲怎么用

前三讲讲的是保险这门生意本身，这一讲讲的是它的「人」：一张保单从投保到理赔，会经过三个岗位——经纪人（broker）、核保人（underwriter）、理赔人（claims adjuster）。考试爱问「这件事是谁的义务」「这是哪一类危险」，选项常常把对客户的义务和对保险公司的义务调个包。第 ④ 节把考试口径和 BC 现行规则并排放好，答卷与上岗各用各的。

① 这一讲考什么

考试形式以 IBABC 现行 FOI 考试页为准：线上作答、100 道单选、2.5 小时、70% 及格。考点对应 Insurance Council of BC 公布的 GICF – Level 1 胜任力框架，官方公开练习卷（IBAS 练习卷 PDF）第 23–26 题落在这一讲；第 11、12 题常被当成这里的内容，其实考点在第 3 讲。

② 一页速览

保险要先申请、价格因人而异，所以不是普通商品。经纪人站在客户和保险公司中间，自己不是合同当事人；他欠客户的是「合理的技能、谨慎与勤勉」，做不到就可能吃 E&O 索赔，头号原因是保障不足；他欠保险公司的是说真话、不藏信息，所以被叫做「首线核保人」。核保人是保险公司的雇员，首要任务是挑出最可能赚钱的风险：看四类信息、分辨两类危险、在五种决定里选一个。出了险，客户先报经纪行，经纪行再报保险公司，由公司理赔人或独立理赔人理算。

③ 精讲

3.1 为什么保险不是普通商品

买一袋米、加一箱油、订一辆车，只要付钱就行，价格对谁都差不多。保险不一样，考试抓两点：

  • 要申请。不是谁都能买：投保单里描述的风险如果不合保险公司的标准，通常就被拒。
  • 价格因人而异。保费随被保风险的各种因素变化，同样的保障，两个人的价钱可以差很多。

一张保单要经过很多人的手：有人定费率、有人做检查、有人收投保单和出单，出了险还要有人及时公正地处理。这一讲讲的就是这些人。

3.2 经纪人：站在中间的人

角色。经纪人和代理人都是客户与保险公司之间的中介（intermediary），不是保险合同的当事人——合同上只有被保险人和保险公司两方。

Agent 与 Broker 的两点区别。行业里把所有销售人员都叫 broker 已成习惯，但法律上两者仍有区别：

Agent 代理人 Broker 经纪人
① 首要义务对谁 保险公司 客户
② 代表几家公司 一家 可以只代表一家，但多数情况下替客户在多家公司之间比较

后面的内容里，凡说「经纪人」，指的就是做销售的人。

对客户的首要义务。经纪人要确保客户得到对的建议和对的保障，法律给的标准是 reasonable skill, care and diligence（合理的技能、谨慎与勤勉）。客户因为他没达到这个标准而亏了钱，可以向经纪人和经纪行提出错误与遗漏（E&O，errors and omissions）索赔。

E&O 的头号原因：保障不足。考试口径里，它占 E&O 索赔的近一半，成因有四种：

  1. 没告诉客户有哪些除外；
  2. 没把保障安排上，或安排得太晚；
  3. 安排了错误的保障；
  4. 对某种保障能不能买到给了错误的说法。

想一个温哥华的场景：客户买房主险，经纪人没提下水道倒灌是除外，后来地下室进水——这就是第 1 种。

其他 E&O 来源共五种：对被保风险的不实陈述或描述错误；取消、续保出错；保单变更出错；处理拖延；违反经纪协议（brokerage agreement）。

E&O 保险。考试口径是：有些省份用法律要求经纪行购买 E&O 保险，让消费者在经纪人失职时不致受损；经纪行的保单覆盖行里全体工作人员，所以个人不必另买。BC 现行规则更严，见第 ④ 节。

⚠️

官方练习卷第 24 题

问 E&O 的主要原因，正确答案是没能正确识别客户的损失风险、没提供所需的保障——就是「保障不足」换个说法。「违反经纪协议」是其他来源之一，不是主因。

对保险公司的首要义务。保险公司有权期待经纪人：

  • 对提交的风险说真话；
  • 不扣下、不隐瞒重要信息。

经纪人因此常被叫做 first line underwriters（首线核保人）：他是最早有机会判断这个风险合不合保险公司承保条件的人。有些经纪人怕客户跑去竞争对手那里，会想把不利的细节悄悄略过，结果是保险公司在风险质量上被蒙在鼓里。考试的态度很明确：对保险公司不诚实，任何理由都站不住。

⚠️

官方练习卷第 23 题：两头都有义务

正确答案是经纪人必须始终如实呈现客户的风险、向保险公司披露所有重要事实。错误选项的套路：说经纪人「只」为客户的最大利益行事（漏了对保险公司的义务）；说必须找「最便宜」的保险公司（义务是给对的建议，不是最低价）；说对所代表的保险公司「没有」义务（完全说反）。

3.3 核保人：替保险公司挑风险的人

他是谁。核保人是保险公司的雇员，不直接向消费者卖保险，所以不需要领牌。经纪人递上投保单要报价、谈续保，最后拍板的是核保人，因此经纪人和所代表公司的核保人关系好不好，直接影响办事快不快。

首要职能：风险选择（risk selection）。核保人的首要任务，是从递上来的风险里挑出对保险公司最可能赚钱的那些。出单、绑定保障、办理退保都不是首要职能。

四个信息源：

信息源 怎么用
投保单 往往一看就能表态。一家入住三十年老木结构楼里的焊接铺，多数核保人没兴趣；一家防火结构、装了自动灭火和防盗报警的书店，哪家公司都愿意接
经纪人 核保人想进一步了解申请人，包括个人和生意上的声誉，经纪人常能补充
损失经验数据 看公司在这类风险上的赔付历史。如果过去 3 到 5 年焊接铺的赔款明显高于该类业务收到的保费，核保人可能拒保，或者提出让风险更好看的改进建议
检查报告 有的保险公司有外勤代表，平时帮经纪行做销售服务，也负责核实投保单、实地看财产；商业险核保人还可能向独立检查机构要报告

两类危险。先分清两个词：peril（风险事故）是造成损失的事件，如火灾、盗窃；hazard（危险）是可能引发风险事故的条件。每个风险里都藏着两类危险。

物质危险（physical hazard）——和场所有关。核保人关注：

  • 建筑结构类型：抵御火、风、地震的能力；
  • 占用性质：这处财产实际怎么用，独立楼里的焊接铺就比同样结构的书店危险；
  • 内务管理：场所整体状况，比如地毯翘边、杂物废料堆满。

物质危险看得见，而且一旦发现常常能降下来：把易燃物存放妥当，修车行、焊接和机加工车间的火灾可能性就会降低；定期清洁，能减少因管理松懈造成的损失。

道德危险（moral hazard）——和人有关，是申请人身上可能引发风险事故的主观特征。三类迹象：

  • 财务状况：手头紧的人比不缺钱的人更可能骗保；
  • 品行：通过交谈了解其商业道德和诚实度；对以往的赔案，核保人可能向理赔人了解是否有可疑之处、金额有没有虚报；
  • 对损失漠不关心：因为有保险就粗心大意，抱着「反正都保了」的心态，不愿花力气防损。这种态度通常出自申请人的性格。

道德危险有时看得见、有时看不见，不仔细调查往往很难发现申请人的财务问题或品行问题——这是它和物质危险最大的差别。

⚠️

官方练习卷第 26 题：查的是人，就是道德危险

核保人去查申请人的以往理赔记录或财务状况，关心的是道德危险。选项里的「异常的物质危险」「场所里的吸烟物品」都是场所层面的；「其他有可保利益的人」和危险无关。 再记一个边界：有些复习材料把「对损失漠不关心」另称 morale hazard。本站按 FOI 考试口径，把它归在道德危险之下，答题照这个来。

核保的五种决定。核保不是精确科学，核保人永远不可能掌握全部事实，也不能保证选中的风险不出险，但仍要做出最好的决定，只有五种：

  1. 拒保；
  2. 按递交的条件接受；
  3. 加费率后接受；
  4. 提高免赔额后接受；
  5. 附带某些条件接受。

有的复习材料把它概括成「四种」，答题按这里的五种。

定价（rating）。谁来算保费，取决于风险的复杂程度：

风险类型 谁定价
个人财产险（房主、租客、共管公寓单元业主） 保险公司发费率手册，经纪人自己算
小企业专用保单 投保单附费率表，经纪人容易填
较复杂的商业风险 全部由核保人定价

比如一家家具店的店东请两家本地经纪行报价，两位经纪人都要靠保险公司核保人定出每项保障的价格；经纪人还常会向两家以上保险公司要报价，挑保障与价格最合客户的那一份交给客户。

保单持有人服务。在很多保险公司，出原始保单的核保人要继续管这张保单：改保单、需要时准备取消通知、准备续保证明。经纪人把核保人当专业人士对待，好处不少：核保人对熟悉信任的经纪人更愿意配合，期限紧时能帮着加快核保，也乐于分享行业知识。

3.4 理赔人：出险之后谁来处理

出了险，被保险人希望得到及时、有效率的处理。流程分两步：

  1. 被保险人报给经纪行。经纪行员工的态度至关重要：不管案子看起来多不起眼，客户既然报了，就说明他觉得这件事很重要。看起来有可能在保障范围内，经纪行就通知保险公司。
  2. 经纪行报给保险公司。保险公司认为可能存在一宗索赔后，安排理算。负责理算的是理赔人（claims adjuster），可以是公司员工，也可以在独立理赔公司工作。
公司理赔人 独立理赔人
是谁 保险公司自己的内部理赔人员 独立理赔公司的人
什么时候用 处理大部分案子 内部人手不够，或这次理算需要特别专长
补充 — 保险公司有时允许经纪行代为指定

客户怎么看经纪行，会被理赔过程影响，所以要持续跟进理赔进度，主动问候被保险人，体现同情、同理和关心。

在 BC 做 Level 1，这一讲的三句实务话

一、牌照条件是你本人被至少 $1M／$2M 的 E&O 覆盖，不是「公司有保险就行」——离职或换行时，问清楚新雇主的保单覆盖不覆盖你。 二、「保障不足」是 E&O 头号原因：每次都把主要除外讲给客户听，客户拒绝建议的保障时留下书面记录。 三、出险时客户找你报案，你转报保险公司；理算是持牌理赔人的事，别替保险公司对赔不赔下结论。

⑤ 易混易错

  1. 经纪人、代理人都不是保险合同当事人；当事人只有被保险人和保险公司。
  2. Agent 偏向保险公司、通常一家；Broker 偏向客户、通常多家——别对调。
  3. 法律标准是合理的技能、谨慎与勤勉，不是「最低保费」，也不是「最大利益」。
  4. E&O 头号原因是保障不足；违反经纪协议、处理拖延、续保出错只是「其他来源」。
  5. E&O 保单覆盖经纪行全体，考试口径说个人不必另买；BC 现行要求每位持牌人都被覆盖，见 ④。
  6. 经纪人对保险公司也有义务：说真话、不隐瞒。隐瞒往往因为怕丢客户——这个理由永远站不住。
  7. 核保人不领牌，因为不直接卖保险；他们是保险公司雇员。
  8. 核保首要职能是挑出最可能盈利的风险；定价、出单、退保服务都是次要的。
  9. 四个信息源：投保单、经纪人、损失经验数据（3–5 年）、检查报告。
  10. Hazard 是条件，peril 是事故：危险是可能引发风险事故的条件。
  11. 物质危险管场所（建筑结构、占用、内务管理），看得见、常能降低；道德危险管人（财务、品行、对损失漠不关心），极难发现。
  12. 「反正有保险」的漠不关心，按考试口径属于道德危险。
  13. 核保决定有 5 种：拒保、原样接受、加费、提高免赔额、附条件。
  14. 个人险经纪人用费率手册自己算；小企业用费率表；复杂商业险全由核保人定价。
  15. 保单持有人服务三件事：改保单、取消通知、续保证明。
  16. 理赔两步：被保险人 → 经纪行 → 保险公司；再小的报案，客户都当回事。
  17. 公司理赔人处理大部分案子；独立理赔人在缺人手或要专长时用；保险公司有时让经纪行代为指定。

  1. 一位客户问你：「我买保险，你是替我说话，还是替保险公司说话？」从法律义务的角度，Agent 和 Broker 的答案分别是什么？
  2. 经纪人为了不丢客户，把客户两次火灾赔款记录从投保单上拿掉了。他违反的是哪一项义务？后果可能落在谁身上？
  3. 同样是核保，为什么说道德危险比物质危险更难处理？各举一个例子。
  4. 说出核保人的五种决定，并指出「保证赔款就接受」为什么不在其中。
  5. 客户打来电话，说邻居家的孩子打碎了一块价值约 $300 的窗户，你怎么办？为什么？
  6. 保险公司人手不够处理一场大风暴之后的理赔，可以怎么办？谁来决定由谁出面？

⑧ 考前要点

  • 保险不是商品：要申请；价格因风险而异。
  • 经纪人是中介，不是合同当事人。Agent 偏向保险公司、通常一家；Broker 偏向客户、通常多家。
  • 对客户：给对的建议与保障；法律标准是 reasonable skill, care and diligence；不达标 → 对经纪人和经纪行的 E&O 索赔。
  • E&O 头号原因是保障不足（近 50%）：没讲除外、没安排或太晚、给错保障、错说能否买到。其他：风险描述错误、取消续保错误、变更错误、处理拖延、违反经纪协议。
  • 对保险公司：说真话、不隐瞒 → 「首线核保人」；为留客户而隐瞒，永远站不住。
  • 核保人：保险公司雇员，不领牌；首要职能是挑最可能盈利的风险；信息源：投保单、经纪人、损失经验数据（3–5 年）、检查报告。
  • Hazard 是可能引发 peril 的条件。物质危险：建筑结构、占用、内务管理——看得见、常可降低。道德危险：财务状况、品行、对损失漠不关心——极难发现。
  • 五种核保决定：拒保、原样、加费、加免赔额、附条件。
  • 定价：个人险费率手册、小企业费率表、复杂商业险由核保人定。保单服务：改单、取消通知、续保证明。
  • 理赔两步：被保险人 → 经纪行 → 保险公司。公司理赔人处理大部分；独立理赔人在缺人手或要专长时用。
  • BC 现行（工作用，不答卷）：每位持牌人都要被 E&O 覆盖（$1M／$2M）；Level 1 不得代保险公司签合同、须在 agent 监督下；理赔人要领牌。
