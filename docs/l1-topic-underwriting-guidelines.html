ℹ️

这一篇为什么要单独学

官方 GICF（https://www.insurancecouncilofbc.com/Website/media/Shared/Documents/GICF-Handbook.pdf）2.1.1 要求持牌人能识别客户风险并找到保护客户利益的办法，指标包括：说明持牌人与核保员在评估客户风险时各自的责任，以及说出常见的一般保险核保准则；1.3.4 还要求了解所代理机构的标准核保准则和准入条件。 这些内容在 第 4 讲 里只是顺带讲。这一篇把「谁做什么、看什么、能怎么决定、说错了什么后果」串成一条线。

① 考试口径：核保的骨架

经纪人与核保员的分工

经纪人 核保员
身份 持牌中介 保险公司雇员；不直接向公众销售，不需持牌
在核保里的角色 第一线核保人：第一个判断风险是否符合保险人准入条件（eligibility requirements）的人 做决定的人；首要职责是挑出最可能为保险人带来盈利的风险
对保险人的义务 如实陈述所提交的风险，不隐瞒重要信息 —
定价 个人财产险常用保险人给的费率手册；小商户用带评分表的投保单 复杂商业风险的费率全由核保员定

✕

对保险人不诚实，没有任何理由说得过去

经纪人有时为了不把客户丢给竞争对手，会回避真相或隐瞒负面信息，结果是保险人被故意误导。考试口径对这种做法的态度很明确：任何情况下都无法自圆其说。

风险选择的四个信息源

  1. 投保单：往往足以让核保员作出初步的肯定或否定判断。例如三十年的木结构楼里的焊接作坊，对比防火建筑里装了自动灭火与防盗报警的书店。
  2. 经纪人：提供客户的个人与经营声誉等补充信息。
  3. 损失经验数据：这类风险过去三到五年的赔付，是否明显超过所收保费。
  4. 检验报告：保险人的外勤人员核实投保信息、实地检验；商业险可委托独立检验机构。

两类危险因素

危险因素（hazard）指可能导致风险事故（peril）发生的条件。

物质危险因素 physical hazard 道德危险因素 moral hazard
是什么 与处所有关、可能导致事故的条件 投保人主观方面、可能导致事故的特征
考试列举 建筑构造、占用性质、内务管理 财务状况、品行、对损失漠不关心
能不能看见 看得见，找到后常可降低 可能看得见也可能看不见，极难发现

⚠️

「漠不关心」在考试口径里归道德危险因素

不少资料会把「因为有保险而疏忽、漠不关心」另叫心态危险因素（morale hazard）。FOI 考试口径没有这个第三类，它把漠不关心写成道德危险因素的第三种表现。考 FOI 时只有两类：物质与道德。 选项里出现 morale hazard 时，按题干指定的口径判断；题干写明按 FOI，就归入道德一类。

五种核保决定

核保不是精确科学，但决定只有五种：

  1. 拒保；
  2. 按所提条件承保；
  3. 加费承保；
  4. 提高免赔额承保；
  5. 附条件承保。

核保员还负责保单服务：批改、必要时发出注销通知、出续保凭证。

② 现行规则：核保准则不是法规，但说错话的后果是法规定的

核保准则是保险人自己的内部规则

核保准则（underwriting guidelines）和准入条件由各保险人自己制定，不是公开法规，不同保险人、不同产品各不相同。GICF 1.3.4 的原话指向「所在机构的产品与服务」，你要熟悉的是你所代理的那几家的准则。上面这些维度（构造、占用、内务管理、防护设施、损失经验、财务状况与品行）就是准则最常见的骨架。

信息不实的后果：BC《Insurance Act》

一手源：https://www.bclaws.gov.bc.ca/civix/document/id/complete/statreg/12001_02

条 内容
s.17 投保时的不实陈述或未披露，只有对合同重要（material）时才使合同无效或可撤销；是否重要是事实问题
s.29 法定条件 1（财产险） 投保人对财产作不利于保险人的虚假描述，或不实陈述、欺诈性遗漏对保险人判断风险重要的情况，合同就与该不实陈述相关的那部分财产无效
s.29 法定条件 4 被保险人知道且能控制的重大风险变化，须及时书面通知保险人或其代理；否则合同就受影响部分无效

对保险人的职业义务：行为守则 §8（r7）

一手源：https://www.insurancecouncilofbc.com/Website/media/Shared/Licensee%20Resources/Resources/Insurance-Council-Code-of-Conduct.pdf

  • 8.2：对与你交易的保险人，须合理询问风险、提供完整准确的信息、及时交付文件与款项、公平准确地介绍其产品、守住保险人给你的授权、及时报告潜在索赔。
  • 8.3 注意义务：保险人依赖持牌人提供的信息作核保决定，所以要作「合理审慎的持牌人在同样情形下会作的询问」。
  • 8.3.1：充分、准确地披露对保险人出单决定重要的任何信息。
  • 8.4.2 违规例：提供并绑定了保险人未授权的条款。

核保结果怎样回到客户

  • 守则 7.3.12：不能按原条件续保时，至少在现有保险到期前 60 天通知客户。
  • 拒保或附条件承保，要把原因和替代方案告诉客户（守则 7.3.5、7.3.6 的全面告知），让客户来得及另找保障。GICF 2.1.1 说的「保护客户利益的可能办法」就是这一步。

🔧

问清、写准，是在保护客户

投保单上一个重要问题答错，后果由客户承担，合同可能部分无效。所以「第一线核保人」这个角色对客户同样重要：把核保员会问的问题先问清，按事实填写，有疑问的写明白、向保险人确认。替客户「美化」投保信息，短期是帮了客户，出险时是害了客户，也违反守则 8.2。

ℹ️

两个口径各用在哪

答题：分类、信息源、五种决定，一律按考试口径答。 实务：投保信息的法律后果看 Insurance Act s.17 与法定条件；对保险人的义务看守则 §8；续保通知看守则 7.3.12。

④ 易混易错

  • 核保员不需持牌，经纪人需要。别把「第一线核保人」理解成经纪人有承保权；有承保权的是 MGA 一类获授权的中介，见 MGA 与委托权限。
  • 危险因素（hazard）、事故原因（peril）、风险（risk）是三件事：hazard 是条件，peril 是事故原因，risk 是损失的不确定性。
  • 道德危险因素的三种表现：财务状况、品行、漠不关心，FOI 全部归入道德一类。
  • 五种决定里没有「降费」：拒保、照原样、加费、加免赔额、附条件。
  • 重要性是事实问题，不是保险人说重要就重要。
  • 法定条件 1 的后果是相关财产那部分无效，不是整张保单自动全部无效。

⑥ 自测入口

开始练本篇的题，共 8 道英文四选一，其中 2 道在模考专属池。再口述几个问题：

  1. 经纪人和核保员，谁需要持牌，谁做最终决定？
  2. 风险选择的四个信息源是什么？
  3. 一家工厂主人对失火毫不在意，在 FOI 里归哪类危险因素？
  4. 核保决定有哪五种？
  5. 客户在投保单上漏填了一项重要信息，合同会怎样？

⑦ 考前要点

  1. 经纪人是第一线核保人；核保员是保险公司雇员，不需持牌，做决定。
  2. 四个信息源：投保单、经纪人、损失经验、检验报告。
  3. 两类危险因素：物质（构造、占用、内务管理）、道德（财务、品行、漠不关心）。
  4. 五种决定：拒保、照原样、加费、加免赔额、附条件。
  5. 实务：s.17 只有重要的不实才影响合同；法定条件 1 后果限于相关财产。
  6. 实务：守则 8.2 合理询问、完整准确、守住授权；不能按原条件续保须提前 60 天通知。
